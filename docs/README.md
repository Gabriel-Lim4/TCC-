# Documentação do Eyesight

- **`tcc/`** — material para o TCC.
  - `diario-de-bordo.md`: diário de bordo de 08/10 a 11/10/2026 (o que foi decidido, construído, o que deu errado e como foi resolvido).
  - `arquitetura-e-seguranca.md`: arquitetura, modelo de dados, fluxos, API, segurança/LGPD e testes.
  - `roteiro-teste-de-usabilidade.md`: roteiro do teste com usuários (tarefas, SEQ, SUS).
  - `roteiro-de-apresentacao.md`: roteiro de 5 minutos, plano B e perguntas prováveis da banca.
- **`superpowers/specs/`** — especificações (o desenho de cada melhoria, com decisões e o que ficou de fora).
- **`superpowers/plans/`** — planos de implementação (tarefas com testes escritos antes do código).
- **`superpowers/audits/`** — auditorias (acessibilidade e medição do tema).
